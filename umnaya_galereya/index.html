Что такое «Умная галерея»

Сервис для загрузки и AI-анализа фотографий: детекция лиц, оценка размытия и качества, поиск дубликатов. Обработка асинхронная — фото попадают в очередь Kafka, а gRPC-анализатор возвращает метаданные и превью.

Фото хранятся в MinIO (S3-совместимое хранилище), метаданные — в PostgreSQL 16. API написан на Python 3.14 + FastAPI и разворачивается через Docker Compose или Kubernetes.
